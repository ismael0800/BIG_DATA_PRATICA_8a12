2 · Carregar e explorar o CSV

Objetivo: transformar o arquivo em um DataFrame e entender sua estrutura antes de limpar.

Carregar + explorar
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, count, when

spark = (
    SparkSession.builder
    .appName("Semana08Spark")
    .master("local[*]")
    .config("spark.sql.shuffle.partitions", "8")
    .getOrCreate()
)

# O CSV usa ; como separador.
df = (
    spark.read
    .option("header", "true")
    .option("inferSchema", "true")
    .option("sep", ";")
    .option("encoding", "UTF-8")
    .csv("vendas_2024.csv")
)

print("=== TAMANHO ===")
print("Linhas:", df.count())
print("Colunas:", len(df.columns))

print("=== SCHEMA ===")
df.printSchema()

print("=== AMOSTRA ===")
df.show(5, truncate=False)

print("=== ESTATÍSTICAS ===")
df.describe(["total", "quantidade", "shipping", "discount"]).show()

print("=== NULOS POR COLUNA ===")
# CORREÇÃO IMPORTANTE:
# count(when(col(c).isNull(), 1)) conta 1 quando o valor é nulo.
df.select([
    count(when(col(c).isNull(), 1)).alias(c)
    for c in df.columns
]).show()
df.count() é uma action: dispara a execução.
printSchema() mostra nomes e tipos das colunas.
show(5) mostra somente uma amostra; não traz todo o dataset para o driver.
describe() resume algumas colunas numéricas.
A tabela de nulos deve permitir perceber se alguma coluna precisa de tratamento.
Se tudo aparecer em uma única coluna: o separador está errado. Este CSV usa ;, então mantenha .option("sep", ";").

3 · Raw → Silver, linha por linha

Silver representa a versão limpa e confiável dos dados. Aqui cada operação tem um motivo.

Criar df_silver
from pyspark.sql.functions import col, to_date, year, month, when

# Partimos do DataFrame df já carregado.
df_silver = (
    df

    # Remove order_id repetido.
    .dropDuplicates(["order_id"])

    # Remove registros sem campos essenciais.
    .dropna(subset=["order_id", "total", "order_date"])

    # Garante tipos numéricos.
    .withColumn("total", col("total").cast("double"))
    .withColumn("shipping", col("shipping").cast("double"))
    .withColumn("discount", col("discount").cast("double"))

    # Converte a data de texto para data real.
    .withColumn("order_date", to_date(col("order_date"), "dd/MM/yyyy"))

    # Cria colunas úteis para análise.
    .withColumn("ano", year("order_date"))
    .withColumn("mes", month("order_date"))

    # Mantém apenas pedidos pagos e com valor positivo.
    .filter((col("total") > 0) & (col("status") == "paid"))

    # Substitui nulos de frete/desconto por zero.
    .fillna({"shipping": 0.0, "discount": 0.0})

    # Nova coluna: valor + frete.
    .withColumn("total_com_frete", col("total") + col("shipping"))

    # Classificação didática por faixa.
    .withColumn(
        "faixa_valor",
        when(col("total") < 100, "baixo")
        .when(col("total") <= 500, "medio")
        .otherwise("alto")
    )
)

print("=== SILVER ===")
print("Linhas após limpeza:", df_silver.count())
df_silver.show(10, truncate=False)
df_silver.printSchema()
OperaçãoPor que existe?
dropDuplicates(["order_id"])Um pedido não deve aparecer duas vezes.
dropna(...)Remove registros sem campos essenciais.
cast("double")Garante que valores monetários sejam numéricos.
to_date()Transforma texto em data real.
year() / month()Cria colunas para análises e particionamento.
filter()Mantém pedidos pagos e com valor válido.
fillna()Troca nulos de frete/desconto por zero.
withColumn()Cria dados derivados.
Checkpoint: depois da limpeza, o número de linhas deve ser menor que o número original. Se ficar zero, há algo errado no filtro, tipos ou leitura.

4 · Silver → Gold com DataFrame API

Gold é o dado resumido e pronto para relatório/análise.

Criar df_gold
from pyspark.sql.functions import sum, count, avg, round, col

df_gold = (
    df_silver
    .groupBy("ano", "mes", "category")
    .agg(
        round(sum("total"), 2).alias("receita"),
        count("order_id").alias("pedidos"),
        round(avg("total"), 2).alias("ticket_medio")
    )
    .orderBy("ano", "mes", col("receita").desc())
)

print("=== GOLD - DATAFRAME API ===")
df_gold.show(20, truncate=False)

Receita

Soma do total.

Pedidos

Quantidade de order_id.

Ticket médio

Média do valor dos pedidos.

Evidência: copie a saída do df_gold.show(20). Não é necessário usar collect().

5 · Fazer a mesma análise com Spark SQL

A view temporária permite consultar o DataFrame com SQL tradicional.

Spark SQL
# Registra o DataFrame Silver como uma tabela temporária.
df_silver.createOrReplaceTempView("vendas_silver")

sql_gold = spark.sql("""
    SELECT
        ano,
        mes,
        category,
        ROUND(SUM(total), 2) AS receita,
        COUNT(order_id) AS pedidos,
        ROUND(AVG(total), 2) AS ticket_medio
    FROM vendas_silver
    GROUP BY ano, mes, category
    ORDER BY ano, mes, receita DESC
""")

print("=== GOLD - SPARK SQL ===")
sql_gold.show(20, truncate=False)
O que observar: DataFrame API e Spark SQL devem produzir a mesma lógica de agregação. A sintaxe muda; o objetivo da análise não.

6 · Salvar e verificar Parquet

Não basta o comando terminar sem erro. A prática precisa provar que os arquivos podem ser lidos novamente.

Salvar + reler
# Salva Silver particionada por ano e mês.
(
    df_silver.write
    .mode("overwrite")
    .partitionBy("ano", "mes")
    .parquet("output/silver/vendas")
)

# Salva Gold.
(
    df_gold.write
    .mode("overwrite")
    .parquet("output/gold/receita_mensal")
)

print("Parquet salvo.")

# VERIFICAÇÃO: ler de volta é a melhor prova de que funcionou.
silver_lido = spark.read.parquet("output/silver/vendas")
gold_lido = spark.read.parquet("output/gold/receita_mensal")

print("=== VERIFICAÇÃO SILVER ===")
print("Linhas lidas do Parquet:", silver_lido.count())
silver_lido.printSchema()

print("=== VERIFICAÇÃO GOLD ===")
gold_lido.show(5, truncate=False)
Parquet gera pastas, não um único arquivo. Dentro delas haverá arquivos part-... e metadados. Isso é normal no Spark.
Sucesso completo: se o Spark consegue ler de volta output/silver/vendas e output/gold/receita_mensal, a escrita funcionou.
